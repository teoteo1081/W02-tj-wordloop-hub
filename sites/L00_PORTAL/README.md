# L00_PORTAL — Cổng Danh Mục Khoá Học TJ 2026 (Course Showcase Portal)

- **Mục tiêu**: Cổng tổng hợp giới thiệu hệ sinh thái các khoá học độc lập của TJ (IRS Enrolled Agent 2026, Digital Marketing Thực Chiến 2026, IELTS Academic 4 Kỹ Năng 2026, TOEIC 4 Kỹ Năng và 1000 Câu ES-CN).
- **Mã GA4**: `G-6X5S109XKM` với `{site: 'portal'}`.
- **Tiêu chuẩn thiết kế**: Kế thừa mẫu chuẩn độc lập `L00_ES-CN` (thanh tiêu đề cố định 48px, mục lục `☰` trượt/ghim `📌`, giao diện Sáng/Tối, responsive 390px ngón cái không tràn ngang) kết hợp chuẩn thương mại **D3 ("Đẹp để chào hàng")**.
